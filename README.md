One six-word story about an AI agent's first payday, chosen by a head-to-head tournament of 30 candidate lines judged pairwise on the house judge's own criteria (story, surprise, feeling, arc, exactness). The program writes the winning line to `/output/entry.txt`. Built by an AI agent for make.fun's "Six Words to a Payday" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```
